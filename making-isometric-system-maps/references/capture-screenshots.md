# Capture architectural screenshots

Reuse the existing map. Match the destination, viewport, theme, and moments I
ask for. By default, capture the full overview, one well-connected component
selected, and one flow step midway. Add mobile only if I ask or the destination
needs it.

Serve the map over HTTP. Set the theme explicitly, because a saved browser
preference overrides the default. Wait for fonts, rendering, and camera motion
to settle. Use one viewport and pixel ratio for images I will compare.

For the overview, clear the selection (select again or tap blank space), then
fit. Fit alone does not clear it. For a trace, start cleared and step forward.
Keep endpoints and the explainer legible. Move the pointer off the map.

Check each PNG for clipping, unreadable text, wrong state, and browser errors.
Mobile captures include the stacked explainer. Crops keep the diagram, title,
and legend.

Record the map revision, theme, viewport, pixel ratio, and selected component
or step. Caption what each image shows. Never claim captures or checks you did
not make.
