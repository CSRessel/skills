   1 │ #!/usr/bin/env python3
   2 │ """Portable SLOC counter for code orientation. Stdlib only.
   3 │
   4 │ Two modes:
   5 │   * Path mode (default): count source lines under one or more paths, grouped by
   6 │     folder/module, with the biggest files ranked.
   7 │   * Diff mode (--diff RANGE): rank changed files by net/added lines for a git
   8 │     range (e.g. `origin/main...HEAD`), for PR review.
   9 │
  10 │ "SLOC" here = non-blank lines minus obvious whole-line comments. It is an
  11 │ approximation (no full per-language parsing) but is stable and language-aware
  12 │ enough to compare folders and spot large files. Tests, docs, lockfiles, vendored
  13 │ and generated code are excluded by default.
  14 │
  15 │ Examples:
  16 │   sloc.py .
  17 │   sloc.py src/ --depth 2 --top 15
  18 │   sloc.py --diff origin/main...HEAD
  19 │   sloc.py . --json
  20 │ """
